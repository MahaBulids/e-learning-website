PHP and Databases

PHP can interact with databases to store, retrieve, and manipulate data. The most common database used with PHP is MySQL, but PHP supports others like PostgreSQL, SQLite, and Oracle.

  • Create dynamic web applications that store user data.
  • Manage content in CMS (like WordPress).
  • Handle eCommerce products, orders, and users.

Connecting PHP to MySQL

PHP provides mysqli and PDO to connect to databases. Example using MySQLi:

<?php
$servername = "localhost";
$username = "root";
$password = "";
$dbname = "mydatabase";

// Create connection
$conn = new mysqli($servername, $username, $password, $dbname);

// Check connection
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}
echo "Connected successfully";
?>

✔ Explanation:
- new mysqli() creates a database connection.
- connect_error checks if the connection failed.
- If successful, a message "Connected successfully" is displayed.

Creating a Table

<?php
$sql = "CREATE TABLE Students (
    id INT(6) UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(50),
    reg_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)";

if ($conn->query($sql) === TRUE) {
    echo "Table Students created successfully";
} else {
    echo "Error creating table: " . $conn->error;
}
?>

✔ Explanation:
- CREATE TABLE SQL command is used.
- Columns include id (primary key), name, email, and reg_date.
- PHP executes the SQL with $conn->query().

Inserting Data

<?php
$sql = "INSERT INTO Students (name, email) VALUES ('Alice', 'alice@example.com')";

if ($conn->query($sql) === TRUE) {
    echo "New record created successfully";
} else {
    echo "Error: " . $sql . "<br>" . $conn->error;
}
?>

✔ Explanation:
- INSERT INTO adds a new record.
- Check success with $conn->query().
- Display error if query fails.

Retrieving Data

<?php
$sql = "SELECT id, name, email FROM Students";
$result = $conn->query($sql);

if ($result->num_rows > 0) {
    // Output data of each row
    while($row = $result->fetch_assoc()) {
        echo "ID: " . $row["id"]. " - Name: " . $row["name"]. " - Email: " . $row["email"]. "<br>";
    }
} else {
    echo "0 results";
}
?>

✔ Explanation:
- SELECT retrieves data from the table.
- fetch_assoc() fetches each row as an associative array.
- num_rows checks if there are any results.

Updating Data

<?php
$sql = "UPDATE Students SET email='alice_new@example.com' WHERE name='Alice'";

if ($conn->query($sql) === TRUE) {
    echo "Record updated successfully";
} else {
    echo "Error updating record: " . $conn->error;
}
?>

Deleting Data

<?php
$sql = "DELETE FROM Students WHERE name='Alice'";

if ($conn->query($sql) === TRUE) {
    echo "Record deleted successfully";
} else {
    echo "Error deleting record: " . $conn->error;
}
?>

Closing the Connection

<?php
$conn->close();
?>

Always close the database connection to free up resources.

Summary

  • PHP can connect to databases using MySQLi or PDO.
  • CRUD operations: Create, Read, Update, Delete can be performed via PHP.
  • Always check for connection and query errors.
  • Close the connection after operations to save resources.
