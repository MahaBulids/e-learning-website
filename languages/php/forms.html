PHP Forms

Forms are used in web pages to collect user input. PHP can process this input and perform actions like storing data, sending emails, or validating user entries.

Creating a Simple HTML Form

This form collects a user's name and email:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>PHP Form Example</title>
</head>
<body>

<form action="process.php" method="post">
  Name: <input type="text" name="name"><br>
  Email: <input type="email" name="email"><br>
  <input type="submit" value="Submit">
</form>

</body>
</html>

✔ Explanation:
- action="process.php" specifies the PHP file that will process the form.
- method="post" sends data securely in the request body.
- name attribute identifies the form input for PHP to use.

Processing Form Data in PHP

In process.php, we can access form data using $_POST:

<?php
  $name = $_POST['name'];
  $email = $_POST['email'];

  echo "Hello, " . $name . "!
    

      ✔ Explanation:

      - $_POST['name'] retrieves the value entered in the "name" field.

      - $_POST['email'] retrieves the email.

      - echo displays the input back to the user.

GET vs POST Methods

  • GET: Appends data to the URL. Useful for bookmarks or queries. Less secure.
  • POST: Sends data in the request body. More secure for sensitive information.

Validating Form Data

<?php
  if(isset($_POST['name']) && isset($_POST['email'])) {
      $name = $_POST['name'];
      $email = $_POST['email'];

      if(empty($name) || empty($email)) {
          echo "Please fill in all fields!";
      } else {
          echo "Name: " . $name . "<br>";
          echo "Email: " . $email;
      }
  }
?>

✔ Explanation:
- isset() checks if the form values exist.
- empty() ensures the user entered data.
- Provides basic validation before processing the data.

Summary

  • Forms collect user input via HTML.
  • PHP uses $_POST or $_GET to access form data.
  • action specifies the processing PHP file.
  • Always validate form data to ensure security and completeness.
  • Use POST for sensitive data and GET for simple queries.
