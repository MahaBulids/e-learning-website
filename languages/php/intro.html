Introduction to PHP

PHP (Hypertext Preprocessor) is a server-side scripting language designed for web development. PHP code is executed on the server, and the output (usually HTML) is sent to the browser.

PHP allows you to create dynamic web pages, interact with databases, handle forms, sessions, cookies, and much more.

Basic Syntax of PHP

  • PHP code starts with <?php and ends with ?>.
  • Statements end with a semicolon ;.
  • Comments can be written as // single line or /* multi-line */.
  • PHP is case-insensitive for keywords but case-sensitive for variables.

Simple PHP Example

This example displays a greeting message using PHP:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>PHP Example</title>
</head>
<body>

<?php
  // Display a greeting message
  echo "Hello, welcome to PHP!";
?>

</body>
</html>

✔ Explanation:
- <?php ?> encloses PHP code.
- echo outputs the text to the browser.
- This code will display: Hello, welcome to PHP!

Variables in PHP

Variables store data and start with the $ symbol:

<?php
  $name = "Alice";
  $age = 25;
  echo "Name: " . $name . ", Age: " . $age;
?>

✔ Explanation:
- $name and $age are variables.
- echo displays text and variable values.
- . is used to concatenate (join) strings.

Summary

  • PHP is a server-side scripting language for dynamic web pages.
  • PHP code is enclosed in <?php ?> tags.
  • echo is used to display output.
  • Variables start with $ and store data.
  • Comments help explain code: // for single line, /* */ for multi-line.
