Introduction to C++

C++ is a general-purpose, object-oriented programming language developed by Bjarne Stroustrup in 1983 as an extension of C. It is widely used for developing system software, applications, and high-performance programs.

  • Compiled Language – C++ code is converted into machine code by a compiler before execution.
  • Portable – The same program can run on different platforms with minimal changes.
  • Object-Oriented – Supports concepts like classes, objects, and inheritance.
  • High Performance – Used where speed and efficiency are critical.

Basic Structure of a C++ Program

#include <iostream>   // Header file for input and output
using namespace std;  // Standard namespace

int main() {
    cout << "Hello, World!";  // Output statement
    return 0;                  // End of program
}

Explanation of code:

  • #include <iostream> – Includes the Input/Output stream library for using cout and cin.
  • using namespace std; – Allows direct use of standard library names without std:: prefix.
  • int main() – Entry point of every C++ program.
  • cout – Used for displaying output on the screen.
  • return 0; – Ends the program successfully.

Basic Input and Output Example

#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "Enter your age: ";
    cin >> age;   // Taking input
    cout << "You are " << age << " years old.";
    return 0;
}

Explanation:

  • cin – Used to take input from the user.
  • cout – Used to display output.
  • Variables like int age store data entered by the user.

Key Points to Remember

  • Every C++ program must have a main() function.
  • Statements end with a semicolon (;).
  • Comments are written using // for single-line or /* */ for multi-line.
  • C++ is case-sensitive (e.g., Age and age are different).
