Classes in C++

A class in C++ is a blueprint for creating objects. It bundles data (attributes) and functions (methods) that operate on the data into a single unit. This is the foundation of Object-Oriented Programming (OOP).

Basic Syntax of a Class

class ClassName {
  access_specifier:
    // data members (variables)
    // member functions (methods)
};

Explanation:

  • class – Keyword used to define a class.
  • access_specifier – Defines visibility of members (public, private, protected).
  • data members – Variables inside a class.
  • member functions – Functions inside a class that define behavior.

Example: Defining and Using a Class

#include <iostream>
using namespace std;

class Student {
  public:              // Access specifier
    string name;       // Data member
    int age;           // Data member

    void introduce() { // Member function
        cout << "Hi, my name is " << name 
             << " and I am " << age << " years old.";
    }
};

int main() {
    Student s1;           // Create an object of Student
    s1.name = "Alice";    // Assign values
    s1.age = 20;
    s1.introduce();       // Call member function
    return 0;
}

Output: Hi, my name is Alice and I am 20 years old.

Access Specifiers in C++ Classes

  • public – Members are accessible from outside the class.
  • private – Members can be accessed only within the class (default if not specified).
  • protected – Members are accessible in the class and by derived (child) classes.

Key Points

  • A class defines a blueprint, and objects are instances of the class.
  • Helps in data encapsulation and reusability.
  • Access specifiers control data security and privacy.
  • Functions inside a class operate on the data of that class.
