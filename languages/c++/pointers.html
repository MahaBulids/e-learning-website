Pointers in C++

A pointer is a variable that stores the memory address of another variable. Instead of holding a value directly, a pointer holds the location where the value is stored.

Why Use Pointers?

  • To directly access and manipulate memory.
  • To work with dynamic memory allocation.
  • To improve performance by avoiding unnecessary copying.
  • To enable data structures like linked lists, trees, and graphs.
  • To allow functions to modify actual variables (pass by reference).

Basic Syntax

dataType *pointerName;

Explanation:

  • * – Used to declare a pointer.
  • & – "Address of" operator, gives the memory location of a variable.
  • * (dereference operator) – Accesses the value stored at that memory address.

Example: Using Pointers

#include <iostream>
using namespace std;

int main() {
    int num = 10;
    int *ptr;        // Declare pointer
    ptr = #      // Store address of num

    cout << "Value of num: " << num << endl;
    cout << "Address of num: " << &num << endl;
    cout << "Pointer holds: " << ptr << endl;
    cout << "Value at pointer: " << *ptr << endl;

    return 0;
}

Output (example): Value of num: 10
Address of num: 0x7ffee3c8a
Pointer holds: 0x7ffee3c8a
Value at pointer: 10

Pointer Types

  • Null Pointer – Points to nothing (int *ptr = NULL;).
  • Void Pointer – Can point to any data type (void *ptr;).
  • Dangling Pointer – Points to a memory location that has been freed.
  • Wild Pointer – An uninitialized pointer with an unknown address.
  • Function Pointer – Points to a function, used for callbacks.
  • Pointer to Pointer – A pointer storing the address of another pointer.

Key Points

  • Pointers are powerful but must be used carefully to avoid memory issues.
  • Dereferencing a pointer gives access to the actual value stored in memory.
  • Uninitialized or wrongly used pointers may cause segmentation faults.
  • Pointers are essential in dynamic memory, arrays, and data structures.
