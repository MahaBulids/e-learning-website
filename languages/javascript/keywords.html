JavaScript Keywords with Examples

Keywords are reserved words in JavaScript that have a special meaning. They cannot be used as variable names, function names, or identifiers.

Keyword Purpose / Description Example
var Declares a function-scoped variable var name = "Alice";
let Declares a block-scoped variable let age = 25;
const Declares a constant (cannot be reassigned) const PI = 3.14;
if Conditionally executes a block of code if(age > 18){ console.log("Adult"); }
else Specifies an alternative block for if else { console.log("Minor"); }
for Starts a for loop for(let i=0;i<5;i++){ console.log(i); }
while Starts a while loop while(i<5){ i++; }
function Declares a function function greet(){ console.log("Hello"); }
return Returns a value from a function return x + y;
switch Executes different code based on cases switch(day){ case 1: console.log("Mon"); break; default: console.log("Other"); }
break Exits a loop or switch statement for(i=0;i<5;i++){ if(i==3) break; }
continue Skips current iteration of a loop for(i=0;i<5;i++){ if(i==2) continue; }
try Defines a block to test for exceptions try{ let x = y; } catch(e){ console.log(e); }
catch Handles errors thrown in try block catch(e){ console.log("Error:", e); }
class Defines a class class Person { constructor(name){ this.name = name; } }
new Creates an instance of a class let p = new Person("Alice");
this Refers to the current object this.name = "Alice";
typeof Returns the type of a variable typeof 10; // "number"
throw Throws an exception throw "Error occurred";
import Imports modules or objects import { readFile } from 'fs';
export Exports modules or objects export function greet() {}
