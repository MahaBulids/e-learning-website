What is JavaScript?

JavaScript (JS) is a high-level, interpreted, and dynamic programming language mainly used for web development to make websites interactive and dynamic.

  • Runs in web browsers and on servers via Node.js.
  • Can manipulate HTML, CSS, and browser events.
  • Supports object-oriented, functional, and procedural programming styles.

Why Learn JavaScript?

  • It runs directly in browsers — no installation required.
  • Supports both frontend (React, Angular, Vue) and backend (Node.js).
  • Enables dynamic interactivity on web pages.
  • Has vast community support and libraries.

Key Features of JavaScript

  • Interpreted Language – Code runs directly without compilation.
  • Lightweight and Flexible – Suitable for small scripts or large apps.
  • Event-driven – Responds to user actions like clicks or form inputs.
  • Cross-platform – Works on almost all devices with a browser.
  • DOM Manipulation – Dynamically changes content, style, and structure of web pages.
  • Client-side & Server-side – Initially for browser, now also for server with Node.js.

Uses of JavaScript

  • Interactive web pages – Forms validation, animations, pop-ups.
  • Web applications – Gmail, Facebook, dynamic apps.
  • Server-side development – APIs and backend services using Node.js.
  • Game development – Browser-based games.
  • Mobile app development – Using frameworks like React Native.

JavaScript Example

// Displaying a message in console
console.log("Hello, JavaScript!");

// Variables and basic arithmetic
let a = 5;
let b = 10;
console.log("Sum:", a + b);

// Function
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Alice");

Advantages of Learning JavaScript

  • Essential for front-end web development.
  • Large community support and libraries/frameworks (React, Angular, Vue).
  • Can be used for full-stack development with Node.js.
  • Improves web interactivity and user experience.
