Basics of JavaScript

JavaScript (JS) is a high-level, interpreted programming language used mainly for web development to make websites interactive and dynamic.

  • Runs in web browsers and on servers via Node.js.
  • Can manipulate HTML, CSS, and browser events.
  • Supports object-oriented, functional, and procedural programming styles.

1. Variables

Variables are used to store data values. JavaScript provides three ways to declare variables:

  • var: Function-scoped variable (older usage).
  • let: Block-scoped variable (modern usage).
  • const: Block-scoped constant that cannot be reassigned.

2. Data Types

JavaScript has several basic data types:

  • String: Text, e.g., "Hello World"
  • Number: Numeric values, e.g., 10, 3.14
  • Boolean: true or false
  • Undefined: Variable declared but not assigned
  • Null: Represents no value
  • Object: Collections of key-value pairs
  • Array: Ordered list of values

3. Operators

JavaScript uses operators to perform operations on variables and values:

  • Arithmetic: +, -, *, /, %
  • Assignment: =, +=, -=
  • Comparison: ==, ===, !=, !==, >, <, >=, <=
  • Logical: &&, ||, !

4. Functions

Functions are reusable blocks of code that perform a specific task.

  • Declared using function keyword or as arrow functions.
  • Can accept parameters and return values.

5. Conditional Statements

Conditional statements allow executing code based on conditions:

  • if, else if, else statements
  • switch statement for multiple choices

6. Loops

Loops are used to execute a block of code multiple times.

  • for loop
  • while loop
  • do...while loop
  • for...of loop (arrays/iterables)
  • for...in loop (objects)

7. Events

JavaScript can respond to user interactions called events, such as:

  • onclick – when an element is clicked
  • onmouseover – when mouse hovers over an element
  • onload – when a page loads

8. Console

The console is used for debugging and displaying messages:

  • console.log() – prints messages to the console
  • console.error() – prints error messages
  • console.warn() – prints warnings
