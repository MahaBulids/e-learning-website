C# and .NET

C# runs on the .NET framework, which provides libraries and runtime support. C# and .NET are closely related but represent distinct components within the Microsoft development ecosystem.

Relationship between C# and .NET

C# is a programming language that runs on the .NET platform. C# code is compiled into Common Intermediate Language (CIL), which is executed by the .NET runtime. This means that C# leverages features of .NET such as its rich class libraries, cross-platform compatibility (for .NET 5+), and performance optimizations.

.NET Versions

  • .NET Framework – Windows-only
  • .NET Core – Cross-platform, open source
  • .NET 5/6+ – Unified, cross-platform framework

Example Code

using System;

class Program {
    static void Main() {
        Console.WriteLine("Running on .NET!");
    }
}

Line-by-Line Explanation

1) using System;

Imports the System namespace so you can use classes like Console. Without it, you would need to write System.Console.WriteLine(...).

2) class Program { ... }

Defines a class named Program. In C#, all code must reside inside a class or struct. The name can be anything, but Program is a convention for the main entry class.

3) static void Main()

  • static → Method belongs to the class, not to an object.
  • void → Returns nothing.
  • Main → Special method name, the program entry point.

4) Console.WriteLine("Running on .NET!");

Prints the text Running on .NET! to the console, followed by a newline. Console is a class in the System namespace.

Program Flow

  1. The .NET runtime starts and looks for Main().
  2. Executes the code inside Main.
  3. Console.WriteLine prints the message.
  4. The program exits.

Output

Running on .NET!
