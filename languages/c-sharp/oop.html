Object-Oriented Programming (OOP) in C#

C# is a fully object-oriented language. OOP allows developers to build programs using objects (real-world entities) instead of writing everything in a single block of code.

The main principles of OOP in C# are: Encapsulation, Abstraction, Inheritance, and Polymorphism.

1. Classes and Objects

using System;

class Car {
    public string brand;
    public int speed;

    public void Drive() {
        Console.WriteLine(brand + " is driving at " + speed + " km/h");
    }
}

class Program {
    static void Main() {
        Car myCar = new Car();
        myCar.brand = "Tesla";
        myCar.speed = 120;
        myCar.Drive();
    }
}

2. Encapsulation

using System;

class BankAccount {
    private double balance;  // private field

    public void Deposit(double amount) {
        balance += amount;
    }

    public double GetBalance() {
        return balance;
    }
}

class Program {
    static void Main() {
        BankAccount account = new BankAccount();
        account.Deposit(500);
        Console.WriteLine("Balance: " + account.GetBalance());
    }
}

Encapsulation: Hides the data (balance) and exposes only controlled access through methods.

3. Inheritance

using System;

class Animal {
    public void Eat() {
        Console.WriteLine("This animal eats food.");
    }
}

class Dog : Animal {  // Dog inherits from Animal
    public void Bark() {
        Console.WriteLine("The dog barks.");
    }
}

class Program {
    static void Main() {
        Dog myDog = new Dog();
        myDog.Eat();   // Inherited method
        myDog.Bark();  // Dog-specific method
    }
}

4. Polymorphism

using System;

class Animal {
    public virtual void Sound() {
        Console.WriteLine("Animal makes a sound");
    }
}

class Dog : Animal {
    public override void Sound() {
        Console.WriteLine("Dog barks");
    }
}

class Cat : Animal {
    public override void Sound() {
        Console.WriteLine("Cat meows");
    }
}

class Program {
    static void Main() {
        Animal myAnimal = new Dog();  
        myAnimal.Sound();  // Output: Dog barks

        myAnimal = new Cat();
        myAnimal.Sound();  // Output: Cat meows
    }
}

Polymorphism: Same method name but different behaviors depending on the object.

5. Abstraction (using abstract class)

using System;

abstract class Shape {
    public abstract void Draw();  // Abstract method (no body)
}

class Circle : Shape {
    public override void Draw() {
        Console.WriteLine("Drawing a Circle");
    }
}

class Program {
    static void Main() {
        Shape s = new Circle();
        s.Draw();
    }
}
