Introduction to C#

C# (C-Sharp) is a modern, object-oriented programming language developed by Microsoft as part of the .NET framework. It is widely used for building web apps, desktop software, mobile apps, and games.

Basic C# Program

using System;

class Program {
    static void Main() {
        Console.WriteLine("Hello, World!");
    }
}

Explanation:

  • using System; → Imports the System namespace.
  • class Program → Defines a class named Program.
  • Main() → Entry point of the program.
  • Console.WriteLine() → Prints output to the screen.

Variables and Data Types

using System;

class VariablesExample {
    static void Main() {
        int age = 21;
        string name = "Alice";
        double pi = 3.14;
        bool isStudent = true;

        Console.WriteLine("Name: " + name);
        Console.WriteLine("Age: " + age);
        Console.WriteLine("Pi: " + pi);
        Console.WriteLine("Student: " + isStudent);
    }
}

Conditional Statement (if-else)

using System;

class IfElseExample {
    static void Main() {
        int number = 10;

        if (number % 2 == 0) {
            Console.WriteLine(number + " is Even");
        } else {
            Console.WriteLine(number + " is Odd");
        }
    }
}

Loops in C#

using System;

class LoopExample {
    static void Main() {
        // For loop
        for (int i = 1; i <= 5; i++) {
            Console.WriteLine("Count: " + i);
        }

        // While loop
        int j = 1;
        while (j <= 5) {
            Console.WriteLine("While Count: " + j);
            j++;
        }
    }
}

Methods in C#

using System;

class MethodExample {
    static void Main() {
        int result = Add(5, 3);
        Console.WriteLine("Sum = " + result);
    }

    static int Add(int a, int b) {
        return a + b;
    }
}
