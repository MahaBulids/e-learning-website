What is Unity?

Unity is a powerful game development engine and platform used to build 2D, 3D, AR (Augmented Reality), and VR (Virtual Reality) applications. It is widely popular for creating video games across PC, mobile, consoles, and the web.

  • Supports multiple platforms (Windows, Android, iOS, PlayStation, Xbox, WebGL).
  • Provides tools for graphics, physics, animation, and sound.
  • Uses C# as its primary scripting language for logic and interactivity.

How is C# Used in Unity?

In Unity, C# scripts are used to control game objects, handle player input, manage physics, UI, and game logic. Scripts are attached to GameObjects in the Unity Editor to define their behavior.

Basic Unity C# Script Example

// Example: Moving a player object in Unity

using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float speed = 5f;  // Movement speed

    void Update()
    {
        // Get input from keyboard (WASD / Arrow Keys)
        float moveX = Input.GetAxis("Horizontal");
        float moveY = Input.GetAxis("Vertical");

        // Move the player
        transform.Translate(new Vector3(moveX, moveY, 0) * speed * Time.deltaTime);
    }
}

Explanation:

  • MonoBehaviour → Base class every Unity script inherits from.
  • Update() → Called every frame (used for continuous updates like movement).
  • Input.GetAxis() → Reads keyboard/gamepad input.
  • transform.Translate() → Moves the GameObject in the scene.

Other Uses of C# in Unity

  • Game Logic – Scoring system, health, levels.
  • Physics Control – Collisions, gravity, rigid bodies.
  • UI Development – Buttons, menus, scoreboards.
  • AI Programming – Enemy behavior, NPC movement.
  • Networking – Multiplayer games, server-client communication.
