What is OOPs in Java?

OOPs (Object-Oriented Programming System) in Java is a way of programming where we structure code around objects rather than just functions. Objects represent real-world entities with state (variables) and behavior (methods). OOP makes code reusable, modular, and easier to maintain.

Core OOP Principles

  • Encapsulation – Wrapping data and methods into a single unit (class).
  • Inheritance – Allows classes to inherit fields and methods from other classes.
  • Polymorphism – The ability of an object to take many forms (method overriding/overloading).
  • Abstraction – Hiding implementation details and showing only functionality.

Four Main Principles of OOP in Java

1. Encapsulation (Data Hiding)

Wrapping data (variables) and methods (functions) into a single unit (class). Access is controlled using private, public, and protected. This ensures data hiding and security. 

class Student {
    private String name; // hidden data

    // getter
    public String getName() {
        return name;
    }

    // setter
    public void setName(String name) {
        this.name = name;
    }
}

2. Inheritance (Reusability)

Mechanism where a new class (child) acquires properties and behavior of an existing class (parent). It promotes code reusability. Uses extends keyword. 

class Animal {
    void eat() {
        System.out.println("This animal eats food.");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks.");
    }
}

3. Polymorphism (Many Forms)

Ability of an object to take many forms. Two types:
• Compile-time (Method Overloading) → Same method name, different parameters.
• Run-time (Method Overriding) → Subclass redefines a method of its parent. 

// Overloading
class MathUtil {
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; }
}

// Overriding
class Animal {
    void sound() { System.out.println("Animal makes sound"); }
}
class Cat extends Animal {
    void sound() { System.out.println("Cat meows"); }
}

4. Abstraction (Hiding Implementation)

Hiding internal details and showing only essential features. Achieved using abstract classes and interfaces. 

// Abstract class
abstract class Shape {
    abstract void draw();
}
class Circle extends Shape {
    void draw() {
        System.out.println("Drawing a Circle");
    }
}

// Interface
interface Animal {
    void sound();
}
class Dog implements Animal {
    public void sound() {
        System.out.println("Dog barks");
    }
}

Extra OOP Concepts

  • Class – Blueprint for objects
  • Object – Instance of a class
  • Constructor – Special method to initialize objects
  • Association, Aggregation, Composition – Ways classes relate to each other
