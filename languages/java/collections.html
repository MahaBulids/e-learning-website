What are Collections in Java?

A Collection in Java is a framework that provides architecture to store and manipulate groups of objects. Instead of using arrays (which have fixed size), Collections allow dynamic and flexible data storage.

The Java Collections Framework (JCF) provides ready-made classes and interfaces to work with lists, sets, queues, and maps. It is present in the java.util package.

Why Use Collections?

  • Dynamic size (unlike arrays which are fixed).
  • Rich built-in methods for searching, sorting, insertion, deletion.
  • Helps write cleaner, reusable, and efficient code.
  • Supports different data structures (List, Set, Queue, Map).
  • Thread-safe options available (like Vector, Concurrent classes).

Collection Hierarchy in Java

The Collection Framework is broadly divided into:

  • Collection Interface → Root of List, Set, Queue.
  • Map Interface → Works separately (stores key-value pairs).

Main Interfaces and Their Implementations

1. List (Ordered, Allows Duplicates)

A List stores elements in a sequence and allows duplicate values. Index-based access.

  • ArrayList – Resizable array, fast for searching.
  • LinkedList – Doubly linked list, faster insertion/deletion.
  • Vector – Thread-safe, legacy class.
// Example: ArrayList
import java.util.*;
class Example {
    public static void main(String[] args) {
        List fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Mango");
        System.out.println(fruits);
    }
}

2. Set (Unique Elements, No Duplicates)

A Set stores unique elements and does not allow duplicates.

  • HashSet – Stores elements in random order.
  • LinkedHashSet – Maintains insertion order.
  • TreeSet – Stores elements in sorted order.
// Example: HashSet
import java.util.*;
class Example {
    public static void main(String[] args) {
        Set numbers = new HashSet<>();
        numbers.add(10);
        numbers.add(20);
        numbers.add(10); // duplicate ignored
        System.out.println(numbers);
    }
}

3. Queue (FIFO - First In, First Out)

A Queue is used to store elements in order for processing. Follows FIFO principle.

  • PriorityQueue – Elements arranged by natural order or comparator.
  • ArrayDeque – Double-ended queue.
// Example: Queue
import java.util.*;
class Example {
    public static void main(String[] args) {
        Queue q = new LinkedList<>();
        q.add("A");
        q.add("B");
        q.add("C");
        System.out.println(q.poll()); // removes A
        System.out.println(q);
    }
}

4. Map (Key-Value Pairs)

A Map stores data in key-value pairs. Keys are unique, values can be duplicate.

  • HashMap – Fast, stores data in random order.
  • LinkedHashMap – Maintains insertion order.
  • TreeMap – Stores keys in sorted order.
  • Hashtable – Thread-safe, legacy class.
// Example: HashMap
import java.util.*;
class Example {
    public static void main(String[] args) {
        Map map = new HashMap<>();
        map.put(1, "One");
        map.put(2, "Two");
        map.put(3, "Three");
        System.out.println(map);
    }
}

Utility Class: Collections

The Collections class provides useful methods for working with collections, like sorting, searching, reversing, and shuffling. 

import java.util.*;
class Example {
    public static void main(String[] args) {
        List nums = Arrays.asList(5, 2, 8, 1);
        Collections.sort(nums);
        System.out.println("Sorted: " + nums);
        Collections.reverse(nums);
        System.out.println("Reversed: " + nums);
    }
}

Advantages of Collections Framework

  • Reduces programming effort (ready-to-use classes).
  • Improves code quality (well-tested classes).
  • Reusability and maintainability of code.
  • Provides thread-safe options.
  • Supports algorithms (sorting, searching, etc.).
