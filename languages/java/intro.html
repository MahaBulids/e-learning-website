What is Java?

Java is a high-level, class-based, object-oriented programming language that is designed to have as few implementation dependencies as possible. It is widely used for building web apps, mobile apps, desktop applications, and enterprise systems.

Key Features of Java

  • Platform Independent – “Write Once, Run Anywhere” using the JVM.
  • Object-Oriented – Everything is modeled as objects.
  • Robust & Secure – Strong memory management and security features.
  • Multithreaded – Supports concurrent execution of tasks.
  • Huge Community – Lots of libraries, frameworks, and support.

Applications of Java

  • Web Development (Spring, JSP, Servlets)
  • Mobile Development (Android)
  • Enterprise Applications
  • Desktop GUI (JavaFX, Swing)
  • Cloud Computing & Big Data

Taking Input

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = sc.nextLine();

        System.out.print("Enter your age: ");
        int age = sc.nextInt();

        System.out.println("Hello " + name + ", you are " + age + " years old.");
    }
}
