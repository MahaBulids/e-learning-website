What is Java?

Java is a high-level, object-oriented, class-based programming language created by James Gosling in 1995 at Sun Microsystems. It follows the principle "Write Once, Run Anywhere", meaning Java programs can run on any platform with the Java Virtual Machine (JVM).

Features of Java

  • Simple and easy to learn.
  • Object-Oriented (everything revolves around classes and objects).
  • Platform Independent (code runs on JVM, not OS specific).
  • Secure and robust for applications.
  • Supports multithreading for parallel tasks.
  • Large standard library and community support.

Where is Java Used?

  • Web Development (Spring, JSP).
  • Mobile Applications (Android development).
  • Desktop Applications (Swing, JavaFX).
  • Enterprise Applications (banking, finance systems).
  • Big Data & Cloud Computing (Hadoop, Spark).
  • Game Development (e.g., Minecraft).

Java Example

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Explanation:

  • class HelloWorld → Every Java program is inside a class.
  • public static void main(String[] args) → Entry point of the program.
  • System.out.println() → Prints output to the console.
