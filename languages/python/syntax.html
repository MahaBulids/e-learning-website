Python Syntax

Syntax in Python refers to the set of rules that defines how Python programs are written. If the syntax rules are not followed, Python will show a SyntaxError. 

# Correct syntax
if True:
    print("Hello, World!")

Common Syntax Errors

1. Missing Colon

# Wrong
if True
    print("Hello")

# Correct
if True:
    print("Hello")

2. Indentation Error

# Wrong
if True:
print("Hello")

# Correct
if True:
    print("Hello")

3. Unclosed Quotes or Parentheses

# Wrong
print("Hello)

# Correct
print("Hello")

4. Misspelled Keywords

# Wrong
prnt("Hello")

# Correct
print("Hello")

How to Fix Syntax Errors

  • Read the error message carefully – it tells the line number and the issue.
  • Check for missing colons (:) and proper indentation.
  • Always close quotes and parentheses.
  • Use an editor like VS Code, Thonny, or PyCharm to highlight mistakes.
  • Run your code step by step to find where the error appears.
