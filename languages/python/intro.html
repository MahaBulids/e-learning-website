What is Python?

Python is a high-level, interpreted programming language created by Guido van Rossum in 1991. It emphasizes readability, simplicity, and productivity, making it one of the most popular programming languages in the world.

Why Learn Python?

  • Easy to learn and understand due to simple syntax.
  • Supports multiple programming paradigms (procedural, object-oriented, functional).
  • Large standard library with built-in modules.
  • Widely used in fields like web development, data science, AI, machine learning, and automation.
  • Massive community support and resources.

Printing Output

In Python, we use the print() function to display output on the screen. 

# Printing text
print("Hello, World!")

# Printing numbers
print(42)

# Printing multiple items
print("The answer is", 42)

Comments

Comments are notes in your code that Python ignores. They help make the code easier to read. In Python, comments start with a #. 

# This is a single-line comment
print("This line will run")

# print("This line is ignored because it is commented out")

Variables

Variables are used to store data. You can assign values to variables using the = operator. 

# Assigning values to variables
name = "Alice"
age = 20
height = 5.4

# Printing variables
print(name)
print("Age:", age)
print("Height:", height)

Python Example

# Hello World in Python
print("Hello, World!")

# Simple addition
a = 5
b = 10
print("Sum:", a + b)
