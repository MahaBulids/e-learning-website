Loops in Python

In programming, a loop is a control structure that allows you to repeat a block of code multiple times. Instead of writing the same code repeatedly, loops make the program shorter, cleaner, and easier to maintain.

Python provides two main types of loops: for loop and while loop. Additionally, you can control loop execution using break, continue, and pass statements.

1. For Loop

The for loop in Python is used to iterate over a sequence (like a list, tuple, string, or range). It executes a block of code once for each item in the sequence.

Syntax:

for variable in sequence:
    # code to execute

Example 1: Using range()

for i in range(5):
    print("Iteration:", i)

Output:

Iteration: 0
Iteration: 1
Iteration: 2
Iteration: 3
Iteration: 4

Example 2: Iterating through a list

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print("I like", fruit)

Output:

I like apple
I like banana
I like cherry

Example 3: Using for loop with a string

for letter in "PYTHON":
    print(letter)

Output:

P
Y
T
H
O
N

2. While Loop

The while loop is used when you do not know how many times to repeat a block of code. It keeps executing as long as the condition is True.

Syntax:

while condition:
    # code to execute

Example 1: Counting numbers

i = 1
while i <= 5:
    print("Count:", i)
    i += 1

Output:

Count: 1
Count: 2
Count: 3
Count: 4
Count: 5

Example 2: Infinite loop (be careful!)

while True:
    print("This will run forever!")  # press Ctrl+C to stop

Note: Always ensure the condition becomes False at some point, otherwise the loop will never stop running.

3. Loop Control Statements

Sometimes, you may want to skip certain iterations or stop the loop completely. Python provides three statements for this purpose:

1️⃣ break statement

It stops the loop entirely, even if the condition is still True.

for i in range(10):
    if i == 5:
        break
    print(i)

Output:

0
1
2
3
4

2️⃣ continue statement

It skips the current iteration and moves to the next one.

for i in range(5):
    if i == 2:
        continue
    print(i)

Output:

0
1
3
4

3️⃣ pass statement

It does nothing and acts as a placeholder. It is useful when you want to define a loop but not write the logic yet. 

for i in range(3):
    pass  # this loop does nothing for now

4. Nested Loops

A nested loop means a loop inside another loop. The inner loop runs completely for each iteration of the outer loop.

Syntax:

for i in range(outer_limit):
    for j in range(inner_limit):
        # code to execute

Example:

for i in range(3):
    for j in range(2):
        print("i =", i, ", j =", j)

Output:

i = 0 , j = 0
i = 0 , j = 1
i = 1 , j = 0
i = 1 , j = 1
i = 2 , j = 0
i = 2 , j = 1

5. Else with Loops

Loops in Python can have an else block. The else part is executed only when the loop finishes normally (i.e., without a break).

Example:

for i in range(3):
    print("Loop:", i)
else:
    print("Loop completed successfully!")

Output:

Loop: 0
Loop: 1
Loop: 2
Loop completed successfully!

6. Summary Table

Loop Type When to Use Syntax Example
for loop When the number of repetitions is known or fixed. for i in range(5):
while loop When the number of repetitions is unknown; depends on a condition. while i <= 5:
nested loop When looping inside another loop is required. for i in range(3): for j in range(2):

Key Tip: Always test your loop logic to ensure it stops correctly and produces the expected output.
