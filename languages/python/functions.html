Introduction to Functions in Python

A function in Python is a block of reusable code that performs a specific task. Functions help in organizing code, avoiding repetition, and improving readability.

  • Functions are defined using the def keyword.
  • They can take parameters (inputs) and return values (outputs).
  • Python has built-in functions like print(), len(), etc., and you can create user-defined functions.

Basic Function Example

def greet():
    print("Hello, World!")

greet()  # Calling the function

✔ Explanation:
- def greet(): defines a function named greet.
- print("Hello, World!") is the task performed by the function.
- greet() calls the function to execute its code.

Function with Parameters

def greet(name):
    print(f"Hello, {name}!")

greet("Alice")  # Output: Hello, Alice!
greet("Bob")    # Output: Hello, Bob!

✔ Explanation:
- name is a parameter that allows passing input to the function.
- f"Hello, {name}!" formats the string using the parameter value.

Function with Return Value

def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # Output: 8

✔ Explanation:
- return sends the result back to the caller.
- add(5, 3) returns 8, which is stored in result.
- print(result) prints the returned value.

Function with Default Parameters

def greet(name="Guest"):
    print(f"Hello, {name}!")

greet()        # Output: Hello, Guest!
greet("Alice") # Output: Hello, Alice!

✔ Explanation:
- Default parameter value is used if no argument is passed.
- Provides flexibility in function calls.

Function with Arbitrary Arguments

def sum_all(*numbers):
    total = 0
    for num in numbers:
        total += num
    return total

print(sum_all(1, 2, 3, 4))  # Output: 10

✔ Explanation:
- *numbers allows passing any number of arguments.
- The function sums all numbers and returns the total.

Summary

  • Functions in Python are reusable blocks of code that perform specific tasks.
  • Defined using the def keyword.
  • Functions can take parameters and return values.
  • Default and arbitrary arguments provide flexibility in usage.
  • Using functions makes your code cleaner, modular, and easier to maintain.
