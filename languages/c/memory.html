Memory in C

In C programming, understanding memory is crucial because C allows direct manipulation of memory using variables and pointers. Memory refers to the computer's storage used to store data, variables, and program instructions.

Types of Memory in C

C programs use different memory areas for different purposes:

  • Stack Memory:
    • Used for local variables and function calls.
    • Automatically allocated and deallocated when functions are called and return.
    • Follows Last In First Out (LIFO) principle.
  • Heap Memory:
    • Used for dynamically allocated memory via malloc(), calloc(), realloc().
    • Must be manually freed using free() to avoid memory leaks.
  • Data Segment:
    • Stores global and static variables.
    • Divided into initialized data segment (variables with initial values) and uninitialized data segment (BSS) (variables without initial values).
  • Code Segment (Text Segment):
    • Stores the compiled program instructions (executable code).
    • Usually read-only to prevent modification.

Memory Allocation in C

  • Static Memory Allocation: Done at compile-time, e.g., local, global, and static variables.
  • Dynamic Memory Allocation: Done at runtime using:
    • malloc(): Allocate memory
    • calloc(): Allocate and initialize memory to zero
    • realloc(): Resize allocated memory
    • free(): Release allocated memory

Pointers and Memory

Pointers are variables that store the address of another variable in memory:

int x = 10;    // Variable stored in memory
int *ptr = &x; // Pointer storing address of x
  • *ptr can be used to access or modify the value stored at that address.
  • Pointers are essential for dynamic memory allocation and efficient memory management.

Memory Diagram Example

Example showing stack, heap, and global variables:

Global: int g = 5;      // Stored in Data Segment
Stack:  int x = 10;     // Local variable
Heap:   int *arr = malloc(5 * sizeof(int)); // Dynamic memory
Code:   main() {...}    // Program instructions

Key Points to Remember

  • C provides low-level access to memory using pointers.
  • Stack memory is automatically managed, while heap memory must be manually freed.
  • Global and static variables are stored in the data segment.
  • Efficient memory management prevents memory leaks and segmentation faults.
