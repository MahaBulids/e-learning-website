Basics of C Programming

C is a procedural programming language developed by Dennis Ritchie in 1972. It is widely used for system programming, application software, and embedded systems.

  • It is fast, portable, and efficient.
  • Supports structured programming using functions and blocks of code.
  • Forms the foundation for many modern languages like C++, Java, and C#.

Key Components of C

  • Variables: Store data values (e.g., int, float, char).
  • Data Types: Define the type of data a variable can hold.
  • Operators: Perform arithmetic, logical, or relational operations.
  • Control Statements: if, else, switch, for, while, do-while.
  • Functions: Blocks of code that perform specific tasks.
  • Input/Output: Using scanf() and printf().

Structure of a Simple C Program

A basic C program generally includes the following parts:

  • #include <stdio.h>: Includes the standard input/output library.
  • int main(): Entry point of the program.
  • Statements: Code executed inside main(), e.g., printing output.
  • return 0; Indicates successful program execution.

Simple C Program Example

#include <stdio.h>

int main() {
    // Print a message to the screen
    printf("Hello, World!\n");
    return 0;
}

Explanation:

  • printf("Hello, World!\\n"); prints "Hello, World!" to the console.
  • // indicates a comment that is ignored by the compiler.
  • return 0; tells the operating system that the program finished successfully.

Running the Program

Steps to run the program:

  1. Write the code in a text editor and save it with .c extension.
  2. Compile the program using a C compiler (e.g., gcc program.c -o program).
  3. Run the compiled program (./program on Linux/Mac or program.exe on Windows).
  4. The output will display: Hello, World!
