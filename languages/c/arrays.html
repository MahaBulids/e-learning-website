Arrays in C

An array in C is a collection of elements of the same data type stored in contiguous memory locations. Arrays allow storing multiple values using a single variable name.

Why Use Arrays?

  • To store multiple values under a single name.
  • To access elements efficiently using an index.
  • To perform operations like sorting, searching, and iteration easily.

Types of Arrays in C

There are mainly three types of arrays:

  1. One-Dimensional Array
  2. Two-Dimensional Array
  3. Multi-Dimensional Array (more than 2 dimensions)

1. One-Dimensional Array

Stores elements in a single row. Accessed using a single index.

#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    for(int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }
    return 0;
}

Output: 10 20 30 40 50

2. Two-Dimensional Array

Stores elements in rows and columns (matrix form). Accessed using two indices.

#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for(int i = 0; i < 2; i++) {
        for(int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }
    return 0;
}

Output:
1 2 3
4 5 6

3. Multi-Dimensional Array

An array with more than two dimensions. Useful for complex data like 3D graphics or simulation data.

#include <stdio.h>

int main() {
    int arr[2][2][2] = {
        {{1, 2}, {3, 4}},
        {{5, 6}, {7, 8}}
    };

    for(int i=0;i<2;i++){
        for(int j=0;j<2;j++){
            for(int k=0;k<2;k++){
                printf("%d ", arr[i][j][k]);
            }
            printf("\n");
        }
        printf("\n");
    }
    return 0;
}

Output:
1 2
3 4

5 6
7 8

Key Points to Remember

  • Array indices in C start from 0.
  • All elements of an array must be of the same data type.
  • Memory for arrays is contiguous, making access faster.
  • One-dimensional arrays are used for lists, two-dimensional arrays for matrices, and multi-dimensional arrays for complex data.
