Types of Pointers in C

Pointers in C are variables that store the memory address of other variables. There are several types of pointers, each serving a different purpose.

1. Null Pointer

A null pointer is a pointer that points to nothing. It is used to initialize pointers when they are not assigned any memory address yet. 

int *ptr = NULL;
if(ptr == NULL) {
    printf("Pointer is null\n");
}

2. Void Pointer

A void pointer is a generic pointer that can point to any data type. However, it cannot be dereferenced directly without typecasting. 

void *ptr;
int x = 10;
ptr = &x;
printf("%d", *(int*)ptr);  // Typecast needed to access value

3. Wild Pointer

A wild pointer is an uninitialized pointer that points to some random memory location. Using wild pointers can lead to undefined behavior and program crashes. 

int *ptr;  // Wild pointer (not initialized)
*ptr = 10; // Dangerous! Avoid using

4. Dangling Pointer

A dangling pointer points to memory that has already been freed or deleted. Accessing a dangling pointer may cause unexpected behavior. 

int *ptr = (int*) malloc(sizeof(int));
*ptr = 20;
free(ptr);     // Memory freed
// ptr is now a dangling pointer

5. Pointer to Pointer

A pointer to pointer is a pointer that stores the address of another pointer. 

int x = 10;
int *ptr = &x;
int **pptr = &ptr;  // Pointer to pointer

printf("%d", **pptr); // Access value of x (10)

6. Function Pointer

A function pointer stores the address of a function and can be used to call the function indirectly. 

int add(int a, int b) {
    return a + b;
}

int (*fptr)(int, int) = add;  // Function pointer
printf("%d", fptr(5, 10));    // Calls add(5,10)

7. Constant Pointer and Pointer to Constant

  • Constant Pointer: Pointer itself cannot change, but the value it points to can change. 
    int x = 5;
int y = 10;
int *const ptr = &x;  // const pointer
*ptr = 20;            // Allowed
ptr = &y;             // Not allowed
  • Pointer to Constant: Value pointed by pointer cannot change, but pointer can point elsewhere. 
    int x = 5;
int y = 10;
const int *ptr = &x;  // pointer to const
*ptr = 20;            // Not allowed
ptr = &y;             // Allowed

Key Points to Remember

  • Null pointers should be used to initialize pointers that are not assigned yet.
  • Void pointers are generic and require typecasting to access values.
  • Wild and dangling pointers are dangerous and must be avoided.
  • Pointer to pointer and function pointers allow advanced memory and function handling.
  • Constant pointers and pointers to constants provide additional control over memory access.
