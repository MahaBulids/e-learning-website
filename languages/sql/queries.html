What are SQL Queries?

A query in SQL is a request made to the database to perform an action like retrieving, inserting, updating, or deleting data. Queries are written using SQL commands and executed on tables inside a database.

Types of SQL Queries

  • Data Query Language (DQL): Used to fetch data (SELECT).
  • Data Manipulation Language (DML): Insert, update, and delete data.
  • Data Definition Language (DDL): Define or change table structures.
  • Data Control Language (DCL): Manage user permissions.
  • Transaction Control Language (TCL): Handle database transactions.

1. Basic Select Query

The most common query is SELECT, used to retrieve data.

SELECT * FROM Students;

✔ Fetches all rows and columns from the Students table. * means "all columns".

2. Filtering Data with WHERE

The WHERE clause filters results based on a condition.

SELECT Name, Age 
FROM Students
WHERE Age > 18;

✔ Retrieves names and ages of students who are older than 18.

3. Sorting Data with ORDER BY

The ORDER BY clause sorts results in ascending (ASC) or descending (DESC) order.

SELECT * 
FROM Students
ORDER BY Age DESC;

✔ Displays all students sorted by age in descending order.

4. Limiting Results with LIMIT

The LIMIT clause restricts the number of rows returned.

SELECT * 
FROM Students
LIMIT 3;

✔ Returns only the first 3 rows from the Students table.

5. Using Aliases

Aliases give temporary names to columns or tables for better readability. 

SELECT Name AS StudentName, Age AS StudentAge
FROM Students;

✔ Displays results with renamed columns StudentName and StudentAge.

Summary

  • SELECT → Retrieve data
  • WHERE → Filter data
  • ORDER BY → Sort data
  • LIMIT → Restrict rows
  • AS → Create aliases

These are the most frequently used SQL queries and form the base for more advanced queries like JOIN and GROUP BY.
