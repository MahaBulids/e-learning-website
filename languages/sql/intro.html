Getting Started with SQL

SQL uses simple commands (called queries) to interact with a database. A database is made of tables, which store data in rows and columns.

Let’s explore some basic SQL commands with examples and explanations.

1. Creating a Table

The CREATE TABLE command is used to make a new table in a database. 

CREATE TABLE Students (
    ID INT,
    Name VARCHAR(50),
    Age INT
);

✔ This creates a table called Students with three columns: ID (integer), Name (text up to 50 characters), and Age (integer).

2. Inserting Data

The INSERT INTO command adds new records into a table. 

INSERT INTO Students (ID, Name, Age)
VALUES (1, 'Alice', 20);

✔ This adds one student with ID=1, Name='Alice', and Age=20.

3. Retrieving Data

The SELECT command is used to get data from a table. 

SELECT * FROM Students;

✔ The * means "select all columns". This shows the entire Students table with all rows and columns.

4. Updating Data

The UPDATE command modifies existing records. 

UPDATE Students
SET Age = 21
WHERE ID = 1;

✔ This updates Alice’s age to 21, but only for the student with ID=1.

5. Deleting Data

The DELETE command removes records from a table. 

DELETE FROM Students
WHERE ID = 1;

✔ This deletes the student with ID=1 from the Students table.

Summary of Basic SQL

  • CREATE TABLE → Make a new table.
  • INSERT INTO → Add new records.
  • SELECT → Retrieve data.
  • UPDATE → Modify existing records.
  • DELETE → Remove records.

These commands form the foundation of SQL and are used in almost every database project.
