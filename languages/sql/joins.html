What are SQL Joins?

A JOIN in SQL is used to combine data from two or more tables based on a related column. Joins help in retrieving meaningful information by connecting tables together.

Types of SQL Joins

  • INNER JOIN: Returns rows that have matching values in both tables.
  • LEFT JOIN (LEFT OUTER JOIN): Returns all rows from the left table, and matching rows from the right table. Non-matching rows show NULL.
  • RIGHT JOIN (RIGHT OUTER JOIN): Returns all rows from the right table, and matching rows from the left table.
  • FULL JOIN (FULL OUTER JOIN): Returns all rows when there is a match in either left or right table.
  • CROSS JOIN: Returns the Cartesian product of both tables (every row from the first table combined with every row from the second).

Sample Tables

Let’s assume we have two tables:

Students Table

ID Name Age
1Alice20
2Bob22
3Charlie21

Courses Table

ID CourseName StudentID
1Math1
2Physics2
3Chemistry4

1. INNER JOIN

SELECT Students.Name, Courses.CourseName
FROM Students
INNER JOIN Courses
ON Students.ID = Courses.StudentID;

✔ Returns only rows where StudentID matches ID in both tables.

Output:

Name CourseName
AliceMath
BobPhysics

2. LEFT JOIN

SELECT Students.Name, Courses.CourseName
FROM Students
LEFT JOIN Courses
ON Students.ID = Courses.StudentID;

✔ Returns all students, even if they don’t have a course.

Output:

Name CourseName
AliceMath
BobPhysics
CharlieNULL

3. RIGHT JOIN

SELECT Students.Name, Courses.CourseName
FROM Students
RIGHT JOIN Courses
ON Students.ID = Courses.StudentID;

✔ Returns all courses, even if no matching student exists.

Output:

Name CourseName
AliceMath
BobPhysics
NULLChemistry

4. FULL JOIN

Not supported in all databases (e.g., MySQL doesn’t support directly). But conceptually: 

SELECT Students.Name, Courses.CourseName
FROM Students
FULL OUTER JOIN Courses
ON Students.ID = Courses.StudentID;

✔ Combines results of LEFT and RIGHT JOIN. Includes all rows with NULL where no match exists.

5. CROSS JOIN

SELECT Students.Name, Courses.CourseName
FROM Students
CROSS JOIN Courses;

✔ Produces every combination of students and courses. If there are 3 students and 3 courses → 3 × 3 = 9 rows.

Summary

  • INNER JOIN → Matching records only.
  • LEFT JOIN → All left records + matching right.
  • RIGHT JOIN → All right records + matching left.
  • FULL JOIN → All records from both tables.
  • CROSS JOIN → Cartesian product.
