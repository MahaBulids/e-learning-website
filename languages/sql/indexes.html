What are SQL Indexes?

An Index in SQL is a database object that improves the speed of data retrieval operations on a table. It works like an index in a book, allowing the database engine to quickly locate the desired rows without scanning the entire table.

⚠️ However, indexes consume extra memory and can slow down INSERT, UPDATE, and DELETE operations because they need to be updated whenever the data changes.

Why Use Indexes?

  • Speeds up SELECT queries.
  • Improves searching and filtering.
  • Helps with sorting and grouping operations.
  • Provides quick access to specific rows.

Types of Indexes

Index Type Description Example
Primary Index Automatically created when a PRIMARY KEY is defined. Ensures uniqueness and fast access. CREATE TABLE Students (ID INT PRIMARY KEY, Name VARCHAR(50));
Unique Index Ensures all values in a column are unique, but unlike primary key, a table can have multiple unique indexes. CREATE UNIQUE INDEX idx_email ON Users(Email);
Composite Index Index on two or more columns, useful for combined searches. CREATE INDEX idx_name_age ON Students(Name, Age);
Clustered Index Stores the actual table rows in the order of the index. A table can have only one clustered index. CREATE CLUSTERED INDEX idx_student_id ON Students(ID);
Non-Clustered Index Creates a separate structure from the table data. Multiple non-clustered indexes are allowed per table. CREATE NONCLUSTERED INDEX idx_name ON Students(Name);

Example: Without vs With Index

Students Table

ID Name Age
1Alice20
2Bob22
3Charlie21

Query without Index:

SELECT * FROM Students WHERE Name = 'Alice';
-- The database scans all rows (Full Table Scan).

Query with Index:

CREATE INDEX idx_name ON Students(Name);
SELECT * FROM Students WHERE Name = 'Alice';
-- The database uses the index to quickly find "Alice".

Advantages of Indexes

  • Improves query performance significantly.
  • Helps in faster WHERE clause lookups.
  • Speeds up sorting with ORDER BY.
  • Improves JOIN performance.

Disadvantages of Indexes

  • Consumes additional disk space.
  • Slows down INSERT, UPDATE, DELETE because index updates are required.
  • Too many indexes can reduce performance instead of improving it.

Summary

  • Indexes are used to speed up data retrieval in SQL.
  • Different types include Primary, Unique, Composite, Clustered, and Non-Clustered.
  • They improve SELECT queries but may slow down data modifications.
  • Best practice: Use indexes wisely for columns often used in search conditions or joins.
