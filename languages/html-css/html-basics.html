Creating Your First Web Page with HTML

To create your first web page, you only need a text editor (like Notepad or VS Code) and a web browser (like Chrome, Firefox, or Edge). Follow these simple steps:

Step 1: Create a New File

Open your text editor and create a new file. Save it with the extension .html, for example: firstpage.html.

Step 2: Write the Basic HTML Structure

Type the following code in your file:


<!DOCTYPE html>
<html>
  <head>
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my very first HTML web page.</p>
  </body>
</html>

Step 3: Open the File in a Browser

Locate your file (firstpage.html) and double-click it. It will automatically open in your default web browser and display your webpage.

What You Will See

The browser will display the content defined inside the <body> tag: 


Hello, World!
This is my very first HTML web page.

Explanation of the Code

  • <!DOCTYPE html> → Tells the browser this is an HTML5 document.
  • <html> ... </html> → Wraps all HTML content.
  • <head> ... </head> → Contains information about the page (title, metadata).
  • <title> → Sets the name of the webpage shown in the browser tab.
  • <body> ... </body> → Holds the visible content of the page.
  • <h1> → A heading tag (largest heading).
  • <p> → A paragraph of text.

Commonly Used Basic HTML Tags

Tag Purpose Example
<h1> to <h6> Headings (largest to smallest) <h2>Welcome</h2>
<p> Paragraph text <p>This is a paragraph.</p>
<a> Link to another page <a href="https://example.com">Click Me</a>
<img> Display an image <img src="photo.jpg" alt="Sample">
<ul> <li> Unordered (bulleted) list <ul><li>Item 1</li></ul>
<ol> <li> Ordered (numbered) list <ol><li>Step 1</li></ol>
<br> Line break Hello<br>World
<hr> Horizontal line (divider) <hr>

Summary

You just created your first HTML web page 🎉 and also learned the most common tags. With these building blocks, you can start making simple webpages with text, images, links, and lists.
