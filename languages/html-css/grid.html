Introduction to CSS Grid

CSS Grid Layout is a powerful 2D layout system that allows you to create web layouts using rows and columns. Unlike Flexbox (which is 1D), Grid can control both horizontal and vertical alignment at the same time.

How CSS Grid Works

To use Grid, you need a container and its child elements: 


.container {
  display: grid;               /* enables grid */
  grid-template-columns: 100px 100px 100px; /* 3 columns */
  grid-template-rows: 100px 100px;          /* 2 rows */
  gap: 10px;                   /* space between items */
}

Each direct child of .container becomes a grid item placed inside the defined grid.

Grid Terminology

  • Grid Container: The parent element with display: grid.
  • Grid Item: The children inside the grid container.
  • Grid Lines: The dividing lines between rows and columns.
  • Grid Tracks: A row or a column (space between grid lines).
  • Grid Cell: A single box inside the grid (intersection of a row & column).
  • Grid Area: A group of cells combined into one larger region.

Important Grid Properties

For the Container

Property Description Example
grid-template-columns Defines the number and size of columns. grid-template-columns: 1fr 2fr 1fr;
grid-template-rows Defines the number and size of rows. grid-template-rows: 100px auto 50px;
gap (or row-gap, column-gap) Controls spacing between rows and columns. gap: 20px;
justify-items Aligns items horizontally within their cells. justify-items: center;
align-items Aligns items vertically within their cells. align-items: stretch;
grid-template-areas Lets you name areas for a visual layout. 

grid-template-areas:
"header header"
"sidebar main"
"footer footer";

For the Items

Property Description Example
grid-column Controls which column(s) the item spans. grid-column: 1 / 3;
grid-row Controls which row(s) the item spans. grid-row: 2 / 4;
grid-area Places the item into a named grid area. grid-area: header;
justify-self Aligns a single item horizontally inside its cell. justify-self: end;
align-self Aligns a single item vertically inside its cell. align-self: center;

Example: Simple Grid Layout


<!DOCTYPE html>
<html>
<head>
  <style>
    .container {
      display: grid;
      grid-template-columns: 1fr 2fr 1fr;
      grid-template-rows: auto auto;
      gap: 10px;
    }
    .box {
      background-color: steelblue;
      color: white;
      padding: 20px;
      text-align: center;
    }
  </style>
</head>
<body>
  <div class="container">
    <div class="box">Box 1</div>
    <div class="box">Box 2</div>
    <div class="box">Box 3</div>
    <div class="box">Box 4</div>
    <div class="box">Box 5</div>
  </div>
</body>
</html>

This creates a grid with 3 columns and 2 rows. The boxes automatically fill the available grid cells.

Summary

  • Grid is a 2D layout system (works with rows and columns).
  • Use display: grid; on the container.
  • Define columns and rows using grid-template-columns and grid-template-rows.
  • Control spacing with gap.
  • Align items with justify-* and align-* properties.
  • Items can span multiple rows/columns or be placed in named areas.
