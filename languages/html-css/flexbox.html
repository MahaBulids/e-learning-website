Introduction to CSS Flexbox

Flexbox (Flexible Box Layout) is a CSS layout model that makes it easier to design responsive layouts, align items, and distribute space within a container.

With Flexbox, elements inside a container can be arranged horizontally or vertically, and they adjust automatically to different screen sizes.

How Flexbox Works

Flexbox works by turning a container into a flex container using the property: 


.container {
  display: flex;
}

Once applied, all child elements of .container become flex items that follow flexbox rules.

Main Axis and Cross Axis

  • Main Axis: The direction in which flex items are placed (default: row → left to right).
  • Cross Axis: Perpendicular to the main axis (default: column → top to bottom).

You can change the direction of the main axis using flex-direction. 


.container {
  display: flex;
  flex-direction: row;    /* default: items in a row */
  flex-direction: column; /* items in a column */
}

Important Flexbox Properties

For the Container

Property Description Example
flex-direction Defines the direction of items. row | row-reverse | column | column-reverse
justify-content Aligns items along the main axis. flex-start | flex-end | center | space-between | space-around | space-evenly
align-items Aligns items along the cross axis. stretch | flex-start | flex-end | center | baseline
flex-wrap Controls whether items wrap onto a new line. nowrap | wrap | wrap-reverse
align-content Aligns multiple rows of items (when wrapping). stretch | flex-start | flex-end | center | space-between | space-around

For the Items

Property Description Example
flex Shorthand for flex-grow, flex-shrink, flex-basis. flex: 1;
align-self Overrides align-items for a specific item. align-self: center;
order Changes the order of items (default is 0). order: 2;

Example: Centering with Flexbox


<!DOCTYPE html>
<html>
<head>
  <style>
    .container {
      display: flex;
      justify-content: center;
      align-items: center;
      height: 100vh;
      background-color: lightgray;
    }
    .box {
      width: 100px;
      height: 100px;
      background-color: steelblue;
      color: white;
      display: flex;
      justify-content: center;
      align-items: center;
    }
  </style>
</head>
<body>
  <div class="container">
    <div class="box">Centered</div>
  </div>
</body>
</html>

Here, the box is perfectly centered horizontally and vertically using justify-content and align-items.

Summary

  • Flexbox is a 1D layout model (handles rows or columns, not both).
  • Use display: flex; on the container.
  • Control direction, alignment, and wrapping with container properties.
  • Control size, order, and alignment with item properties.
