Overview of HTML and CSS

HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) are the core building blocks of web development. Together, they are used to create and style modern websites.

What is HTML?

HTML is a markup language used to define the structure and content of a webpage. It tells the browser what to display, such as headings, paragraphs, links, images, lists, and more.

  • Provides the skeleton of the website.
  • Uses tags like <h1>, <p>, <a>, <img>.
  • Latest version: HTML5 (supports audio, video, canvas, semantic tags).

Basic HTML Example


<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first web page using HTML.</p>
  </body>
</html>

What is CSS?

CSS is a style sheet language used to control how HTML elements are displayed. It defines colors, fonts, layouts, spacing, and even animations.

  • Makes the webpage visually attractive.
  • Uses selectors and properties to style elements.
  • Latest version: CSS3 (supports animations, flexbox, grid, transitions).

Basic CSS Example


<!DOCTYPE html>
<html>
<head>
  <style>
    body { background-color: lightyellow; }
    h1 { color: darkblue; text-align: center; }
    p { font-size: 18px; color: darkgreen; }
  </style>
</head>
<body>
  <h1>Styled Web Page</h1>
  <p>This text is styled using CSS.</p>
</body>
</html>
