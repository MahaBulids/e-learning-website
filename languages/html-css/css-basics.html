Introduction to CSS

CSS (Cascading Style Sheets) is used to style and format HTML web pages. It controls how elements look — such as colors, fonts, sizes, and layout.

HTML builds the structure of a page, while CSS adds the style.

CSS Syntax

CSS follows a simple rule-based structure: 


selector {
  property: value;
}
  • Selector → The HTML element you want to style (e.g., p, h1).
  • Property → The feature you want to change (e.g., color, font-size).
  • Value → The setting applied to the property (e.g., red, 20px).

Example: Styling a Paragraph


p {
  color: blue;
  font-size: 18px;
}

This means: "Select all <p> (paragraphs) and make their text blue with 18px font size."

Types of CSS

  • Inline CSS → Written inside an HTML tag using the style attribute.
  • Internal CSS → Written inside a <style> block in the HTML <head>.
  • External CSS → Written in a separate .css file and linked with <link>.

Example of All Three


<!DOCTYPE html>
<html>
  <head>
    <!-- Internal CSS -->
    <style>
      h1 { color: green; }
    </style>

    <!-- External CSS -->
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Welcome</h1>

    <p style="color:red;">This is inline CSS</p>
  </body>
</html>

Summary

CSS uses selectors, properties, and values to style web pages. You can apply CSS in three ways — inline, internal, or external. For professional websites, external CSS is most commonly used.
