Introduction to Goroutines

Goroutines are lightweight threads managed by the Go runtime. They allow you to perform concurrent operations in Go without the complexity of traditional threads.

  • Goroutines are cheaper than traditional threads, in terms of memory and scheduling.
  • They are started with the go keyword.
  • Used for tasks like handling multiple requests, parallel computations, or asynchronous operations.

Basic Goroutine Example

package main

import (
    "fmt"
    "time"
)

func sayHello() {
    fmt.Println("Hello from Goroutine!")
}

func main() {
    go sayHello() // Start a goroutine
    time.Sleep(1 * time.Second) // Wait for goroutine to finish
    fmt.Println("Main function finished")
}

✔ Explanation:
- go sayHello(): Starts sayHello function as a goroutine.
- time.Sleep(1 * time.Second): Pauses main function to allow goroutine to execute.
- Without Sleep or proper synchronization, the program may end before the goroutine runs.
- Goroutines run concurrently with the main function.

Multiple Goroutines Example

package main

import (
    "fmt"
    "time"
)

func printNumbers() {
    for i := 1; i <= 5; i++ {
        fmt.Println(i)
        time.Sleep(100 * time.Millisecond)
    }
}

func main() {
    go printNumbers()
    go printNumbers()
    
    time.Sleep(1 * time.Second)
    fmt.Println("Main function finished")
}

✔ Explanation:
- Two goroutines are started simultaneously with go printNumbers().
- Both execute concurrently, printing numbers interleaved.
- time.Sleep ensures the main function waits for them to finish.

Key Points About Goroutines

  • Goroutines are managed by Go runtime scheduler.
  • They share memory by default; use synchronization techniques (like channels) to avoid race conditions.
  • Very lightweight; you can run thousands of goroutines simultaneously.
  • Use channels to communicate safely between goroutines.

Where to Test Goroutines

  • Go Playground – Official online Go editor.
  • Local development with Go installed using go run filename.go.
  • IDE like VS Code or GoLand with Go extensions.

Summary

  • Goroutines enable lightweight concurrency in Go programs.
  • Started using the go keyword.
  • Use synchronization techniques like channels to safely share data.
  • Goroutines make Go highly efficient for parallel tasks and scalable applications.
