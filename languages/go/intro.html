First Go Program

Let’s create a simple Go program that prints "Hello, World!" and understand it line by line:

package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

Line-by-Line Explanation

  • package main: Defines the package name. Every Go program must have a main package if it is executable.
  • import "fmt": Imports the fmt (format) package, which contains functions for formatted I/O, like printing to the console.
  • func main(): Declares the main function, the entry point of the program. Execution starts here.
  • fmt.Println("Hello, World!"): Calls the Println function from the fmt package to print the text to the console.

How to Run This Program

  • Using the Go Compiler: 
    go run filename.go   # Run the program directly
go build filename.go # Compile into an executable
  • Online Editors:
    • Go Playground – Official Go online editor
    • Replit Go
    • JDoodle Go
  • Code Editors/IDEs: VS Code, GoLand, Sublime Text (with Go extensions) can be used for development and testing.

Summary

  • The main function is the starting point of every Go program.
  • Use fmt.Println to output text to the console.
  • Go programs can be executed using the compiler, online editors, or local IDEs.
  • This basic structure is the foundation for all Go programs.
