Introduction to Go Web Servers

Go provides a powerful net/http package to build web servers easily. You can handle HTTP requests, serve content, and build APIs with minimal code.

  • Highly performant due to Go’s concurrency features.
  • Simple and readable code to handle routes and responses.
  • Ideal for REST APIs, static file serving, or backend services.

Basic Go Web Server Example

package main

import (
    "fmt"
    "net/http"
)

func helloHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello, World!")
}

func main() {
    http.HandleFunc("/", helloHandler) // Route "/" handled by helloHandler
    fmt.Println("Server is running on http://localhost:8080")
    http.ListenAndServe(":8080", nil) // Start the server on port 8080
}

✔ Explanation:
- http.HandleFunc("/", helloHandler): Maps the URL path "/" to the handler function helloHandler.
- helloHandler: Responds with "Hello, World!" using fmt.Fprintf.
- http.ListenAndServe(":8080", nil): Starts the web server on port 8080.
- Access the server by visiting http://localhost:8080 in a browser.

Handling Multiple Routes

package main

import (
    "fmt"
    "net/http"
)

func homeHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Welcome to the Home Page!")
}

func aboutHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "This is the About Page!")
}

func main() {
    http.HandleFunc("/", homeHandler)
    http.HandleFunc("/about", aboutHandler)

    fmt.Println("Server running on http://localhost:8080")
    http.ListenAndServe(":8080", nil)
}

✔ Explanation:
- Multiple routes can be handled by mapping URL paths to different handler functions.
- Visiting / calls homeHandler, and /about calls aboutHandler.
- You can expand this to handle more pages or API endpoints.

Serving Static Files

package main

import (
    "net/http"
)

func main() {
    fs := http.FileServer(http.Dir("static")) // "static" folder for files
    http.Handle("/static/", http.StripPrefix("/static/", fs))

    http.ListenAndServe(":8080", nil)
}

✔ Explanation:
- http.FileServer serves files from the "static" directory.
- http.StripPrefix removes the "/static/" prefix from the URL.
- Access files via http://localhost:8080/static/filename.

Where to Test Go Web Servers

  • Local machine with Go installed (go run main.go).
  • Visit http://localhost:8080 in your browser to see the responses.
  • Use tools like Postman or cURL to test API endpoints.

Summary

  • Go’s net/http package allows building web servers quickly and efficiently.
  • Map URL paths to handler functions using http.HandleFunc.
  • Serve static files using http.FileServer.
  • Leverage Go’s concurrency to handle multiple requests efficiently.
  • Test web servers locally using a browser, Postman, or cURL.
